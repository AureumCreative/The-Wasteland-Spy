Mix & Match Bot Modules

Mix & Match Bot Modules

Customization Options for Advanced Users

Alongside the ready-to-use bots, the package also includes interchangeable bot modules.

You can easily customize any included bot to your liking: add, swap, or remove different personality sections, scenario definitions, and example dialogs.

For example, you might use the Standard bot but replace its scenario with the Extended version, or add the Combat Behavior module from the Extended personality to one of the Story bots. Mixing modules may create a few duplicated prompts, but these are easy to spot and remove.

Included Modules

To make customization easier, the following modules are separated into their own folder:

  • Personality modules from all three Core versions (individual sections from the Extended version are included separately)
  • Scenario definitions
    • Setting only (50 / 200 tokens) — designed for use alongside lorebooks or for users who prefer minimal scenario prompts
    • Standard / Extended (400 / 800 tokens) — standalone scenario prompts containing setting, worldbuilding, and faction lore
  • Example Dialogs (500 / 700 / 950 token Core versions)
Modules can be freely combined with the included bots. You can use them to fine-tune Deacon's characterization, scenario detail, and token usage to suit your preferred setup.
